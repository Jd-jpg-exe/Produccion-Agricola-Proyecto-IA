# Producción Agrícola — Proyecto IA I

Análisis exploratorio de datos (EDA) sobre las **Evaluaciones Agropecuarias Municipales (EVA)
2019–2025** de Colombia, como primer entregable del proyecto semestral del curso
**Inteligencia Artificial I** (Grupo C2, 2026-2, Prof. Santiago Gómez).

## Objetivo del proyecto

Desarrollar un modelo de IA para predecir la **producción agrícola** de un cultivo en un
municipio, usando datos históricos, evaluando cómo cambia el error de predicción según el
horizonte temporal (+1, +2, +3, +4 periodos), y comparando esa predicción directa contra una
estimación indirecta obtenida de `Producción = Rendimiento × Área cosechada`.

## Cómo ejecutar el notebook

1. Abre `EDA_Produccion_Agricola_EVA.ipynb` en Google Colab (botón "Open in Colab" o
   `File > Open notebook > GitHub` pegando la URL de este repositorio).
2. Ejecuta todas las celdas (`Entorno de ejecución > Ejecutar todas`). El notebook carga el CSV
   directamente desde este repositorio; no requiere subir nada manualmente.
